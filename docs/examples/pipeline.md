# Pipeline examples

These examples focus on the current `pipeline` package surface: byte tasks and
typed slot-entry tasks.

## Example workspace

```go
type ServiceConfig struct {
	Name    string   `json:"name"`
	Port    int      `json:"port"`
	Routes  []string `json:"routes"`
	Enabled bool     `json:"enabled"`
}

type Service struct {
	Root   layout.Dir                      `layout:"."`
	Config formats.JSONFile[ServiceConfig] `layout:"config.json"`
}

type Workspace struct {
	Root     layout.Dir            `layout:"."`
	Services layout.Slot[*Service] `layout:"services"`
	Output   layout.Dir            `layout:"out"`
}
```

## Format byte files in place

Goal: apply the same byte transform to several files and only write back after
all transforms succeed.

```go
p := pipeline.New(
	pipeline.TaskFromFiles("format", generatedFiles...).
		Transform(gofmtTransform).
		WriteToSources(),
)

_, _ = p.Run(context.Background())
```

Why pipeline fits:

- each file stays a byte item
- transformed bytes are buffered before writeback
- one failure can stop the task before any destination write

## Split generated bytes into a directory

Goal: take one generated byte payload, split it into several files, and control
output shaping.

```go
func splitSections(ctx context.Context, lctx layout.Context, split pipeline.ByteSplitter, item pipeline.Item[pipeline.Blob]) error {
	data, err := split.Read()
	if err != nil {
		return err
	}

	for i, section := range bytes.Split(data, []byte("\n---\n")) {
		split.EmitBytes(fmt.Sprintf("section-%02d.txt", i), section)
	}
	return nil
}

p := pipeline.New(
	pipeline.TaskFromBlob("manual", pipeline.Blob{Name: "manual.txt", Data: generated}).
		Split(splitSections).
		WriteToDir(docsDir),
)
```

Why the destination option matters:

- `WriteToDir` writes by basename under `docsDir`
- `WriteToDirPreserve` keeps relative item paths
- invalid paths are rejected during planning before bytes are written

## Pick one generated artifact

Goal: generate several byte items, then persist only the first matching one.

```go
p := pipeline.New(
	pipeline.TaskFromBlobs("reports",
		pipeline.Blob{Name: "summary.txt", Data: summary},
		pipeline.Blob{Name: "detail.txt", Data: detail},
	).
		Pick(func(item pipeline.Item[pipeline.Blob]) bool {
			return item.Name == "summary.txt"
		}).
		WriteToFile(out.File("summary.txt")),
)
```

Why `Pick` fits:

- sources are already in memory
- the selection rule is local to the task
- the task still uses normal buffered sink planning

## Process typed services

Goal: update typed service configs in memory, then sync only the cached entries.

```go
p := pipeline.New(
	pipeline.TaskFromSlotEntries("enable-services", &ws.Services).
		Filter(func(ctx context.Context, lctx layout.Context, item pipeline.Item[*Service]) (bool, error) {
			cfg := item.Value.Config.MustGet()
			return cfg.Enabled, nil
		}).
		Process(func(ctx context.Context, lctx layout.Context, item pipeline.Item[*Service]) (*Service, error) {
			cfg := item.Value.Config.MustGet()
			cfg.Port = cfg.Port + 1000
			item.Value.Config.Set(cfg)
			return item.Value, nil
		}).
		SyncDeep(),
)
```

Why this stays a typed task:

- every step is still about `*Service`
- `Process` changes `T -> T`
- `SyncDeep` persists only after the typed work completes

## Split typed entries

Goal: expand one cached typed entry into multiple derived entries before a deep
operation.

```go
p := pipeline.New(
	pipeline.TaskFromSlotEntries("split-services", &ws.Services).
		Split(func(ctx context.Context, lctx layout.Context, split pipeline.TypedSplitter[*Service], item pipeline.Item[*Service]) error {
			split.Emit(item)
			split.EmitValue(item.Key+"-copy", item.Value)
			return nil
		}).
		EnsureDeep(),
)
```

Why `Split` fits:

- one cached typed item can fan out to several typed items
- emitted items keep flowing through the same task
- persistence is still explicit via deep operations
